Overview

Dynamic Schema Generator is a production-grade, object-oriented WordPress plugin engineered under the DSG namespace. It solves the critical problem of schema fragmentation and duplicate entity declarations by compiling a single, unified @graph JSON-LD array linking Organization, LocalBusiness, WebSite, WebPage, Article, Service, BreadcrumbList, and FAQPage nodes with persistent @id URIs.

It integrates directly with the Elementor Page Builder by parsing stored post meta JSON trees in PHP memory, extracting FAQ accordion and toggle widgets automatically without DOM scraping overhead or frontend render penalties.

Problem It Solves

Most WordPress sites suffer from fractured structured data: multiple plugins inject competing, unlinked JSON-LD blobs, Elementor accordion widgets require manual duplication into SEO plugins, and local business NAP data frequently falls out of sync across landing pages. Furthermore, outdated schema plugins produce validation warnings in Google Search Console.

Key Features

  • Unified Linked @graph Architecture: Emits a single JSON-LD block in wp_head where entities connect through canonical @id URIs, eliminating duplicate entity declarations.
  • Zero-DOM Elementor JSON Tree Adapter: Recursively traverses _elementor_data JSON structures to dynamically pull accordion and toggle widgets into valid FAQPage schema.
  • LocalBusiness & Organization NAP Manager: Centralized dashboard for business type, coordinates, opening hours, sameAs social profiles, and phone/address attributes.
  • Modular Service Schema Builder: Map dedicated service entities with offers, pricing, provider links, and specific target landing pages.
  • FAQ Builder with Deduplication: Combine page-level custom FAQ pairs with Elementor widgets, automatically deduplicating questions.
  • In-House Schema Preview & Validator: Live admin previewer inspecting generated JSON-LD syntax, required property compliance, and Google Search Console guidelines.
  • Telemetry & Diagnostics Hub: Comprehensive environment checks (PHP version, memory limits, active SEO plugin conflict analysis).
  • Multi-PHP Version CI Matrix: Automated GitHub Actions workflow testing across PHP 7.4, 8.0, 8.1, 8.2, and 8.3 with 20 unit tests and 70 assertions passing.

Install & Usage

Download & Install

# Download the release ZIP:
https://github.com/hamid-digitalmarketer/dynamic-schema-generator/releases/download/v1.0.0/dynamic-schema-generator.zip

# Or clone into your WordPress plugins directory:
cd wp-content/plugins/
git clone https://github.com/hamid-digitalmarketer/dynamic-schema-generator.git

Activation

1. Navigate to WP Admin > Plugins > Installed Plugins.
2. Activate "Dynamic Schema Generator".
3. Open "Dynamic Schema" in the admin sidebar.
4. Configure your Business NAP, Services, and Elementor sync settings.

Run Local Unit Tests

php tests/run-tests.php

FAQ

How does Dynamic Schema Generator extract Elementor content without DOM rendering?

The Elementor adapter directly parses WordPress post meta (_elementor_data) JSON structures in PHP memory, traversing nested container and widget trees to extract accordion and toggle Q&A items without frontend DOM scraping overhead.

Does this plugin conflict with Yoast SEO, Rank Math, or All in One SEO?

No. Dynamic Schema Generator includes an intelligent conflict detection engine that inspects active SEO plugins, allowing site owners to selectively manage schema output or operate seamlessly alongside existing metadata tools.
