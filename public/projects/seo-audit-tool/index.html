Overview

SEO Audit Tool is a Streamlit application that crawls a website and reports on-page SEO issues with interactive Pandas/Plotly charts and CSV export. It is designed for fast, accessible audits of small and medium sites.

Problem It Solves

Small businesses and freelancers rarely have access to enterprise SEO suites. They need a simple tool that turns a URL into a prioritized list of fixable on-page issues.

Target Users

  • Small business owners
  • Freelance SEO practitioners
  • Marketing teams needing quick spot checks

Key Features

  • URL crawl with configurable limits
  • On-page SEO checks (titles, meta, headings, images, canonicals)
  • Interactive charts via Pandas and Plotly
  • CSV export of findings
  • Works offline against bundled sample input for testing

Technologies

  • Python
  • Streamlit
  • Pandas
  • Plotly
  • Requests

Contribution & Skills

Sole author. Built the crawler, the audit rule set, the Streamlit UI and the charting and export layers.

Install & Usage

Install

python -m venv venv
# Windows: venv\Scripts\activate  |  macOS/Linux: source venv/bin/activate
pip install -r requirements.txt

Run

streamlit run app.py

FAQ

Is this the same as SEO Doctor?

No. SEO Audit Tool is a lighter Streamlit app for quick on-page checks, while SEO Doctor is a deeper CLI crawler with 10 technical checks and crawl comparison.

Is there a hosted demo?

No. The app runs locally with streamlit run app.py.
