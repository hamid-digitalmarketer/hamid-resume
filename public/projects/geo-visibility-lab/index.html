Technical SEO

Overview

Geo Visibility Lab is a local SEO tool for tracking Google Business Profile visibility across a 5x5 coordinate grid, auditing NAP consistency across directories, monitoring review signals and exporting Schema.org LocalBusiness JSON-LD.

Problem It Solves

Local businesses cannot see where they actually rank across neighborhoods, and inconsistent name/address/phone data across directories quietly erodes local rankings and Google Business Profile trust.

Target Users

  • Local SEO specialists
  • Multi-location businesses
  • Agencies managing local clients

Key Features

  • 5x5 geo-grid rank tracking across service areas
  • NAP consistency and citation drift audits
  • Review monitoring and velocity insights
  • Schema.org LocalBusiness JSON-LD export
  • CLI and local serve modes
  • CI with ruff, mypy and pytest

Technologies

  • Python
  • Typer
  • FastAPI
  • Pydantic
  • pytest

Contribution & Skills

Sole author. Designed the geo-grid tracking model, NAP audit logic, review analytics and schema generation, plus the CLI and local serve interfaces.

Install & Usage

Install

git clone https://github.com/hamid-digitalmarketer/geo-visibility-lab.git
cd geo-visibility-lab
pip install -e ".[dev]"

Run an audit

geo-lab audit --out-dir reports

Serve locally

geo-lab serve

FAQ

What is a 5x5 geo-grid?

The tool divides a service area into a 5x5 coordinate grid and evaluates local visibility across those grid points instead of a single ambiguous location, giving a more realistic picture of local ranking coverage.

Is there a hosted demo?

No. Geo Visibility Lab runs locally via its CLI or serve mode.
