Technical SEO

Overview

SEO Doctor is a technical SEO crawler and auditor written in Python with a Typer CLI and optional FastAPI server. It performs 10 specialized checks, stores crawl data in SQLite, exports HTML/CSV/JSON reports and compares two crawls to track regressions.

Problem It Solves

Broken links, canonical loops, orphan pages and indexation blocks are invisible to on-page-only audits. Marketing teams need enterprise-grade crawl audits that are fast, repeatable and affordable.

Target Users

  • SEO specialists and consultants
  • Digital marketing agencies
  • Webmasters and site owners

Key Features

  • 10 audit checks: broken links, redirects, metadata, H1s, canonicals, robots, images, sitemap, orphan pages and performance hints
  • Crawl comparison to detect regressions between runs
  • HTML, CSV and JSON report exports
  • SQLite storage for crawl persistence
  • FastAPI serve mode for a local web UI
  • 23 passing tests with CI (ruff, mypy, pytest)

Technologies

  • Python
  • Typer
  • FastAPI
  • Pydantic
  • SQLite
  • pytest

Contribution & Skills

Sole author. Built the BFS crawler with robots.txt and sitemap parsing, the 10-check audit engine, report generators, crawl-comparison logic and the full test suite.

Install & Usage

Install

git clone https://github.com/hamid-digitalmarketer/seo-doctor.git
cd seo-doctor
pip install -e .

Run an audit

seo-doctor crawl https://example.com --max-pages 200
seo-doctor compare --baseline reports/base.json

Serve locally

seo-doctor serve

FAQ

What does SEO Doctor check?

It checks broken links, redirect chains and loops, title and meta description quality, heading structure, canonical tags, robots directives, images, sitemap health, orphan pages and crawl performance hints.

Is SEO Doctor hosted online?

No. SEO Doctor runs from the command line or a local FastAPI server. There is no hosted public demo.
