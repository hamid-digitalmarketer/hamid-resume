Technical SEO

Overview

Ecommerce SEO Optimizer is a Streamlit application that helps optimize large e-commerce product catalogs for search. It analyzes product titles and descriptions, generates SEO recommendations and exports the optimized catalog to Excel with openpyxl.

Problem It Solves

Large product catalogs ship with weak titles and meta descriptions because manual optimization does not scale. Stores lose organic traffic one product page at a time.

Target Users

  • E-commerce managers and SEO teams
  • Store owners on Shopify, WooCommerce or marketplaces
  • Agencies managing retail clients

Key Features

  • Catalog import and analysis
  • SEO recommendations for titles and descriptions
  • Optimized catalog export to Excel (openpyxl)
  • Streamlit interface
  • Test suite (pytest)

Technologies

  • Python
  • Streamlit
  • Pandas
  • openpyxl
  • pytest

Contribution & Skills

Sole author. Built the analysis rules, recommendation engine, Excel export layer and Streamlit interface.

Install & Usage

Install

python -m venv venv
# Windows: venv\Scripts\activate  |  macOS/Linux: source venv/bin/activate
pip install -r requirements.txt

Run

streamlit run app.py

Test

pytest -q

FAQ

What does it optimize?

It analyzes product titles and descriptions and generates concrete SEO recommendations, then exports an optimized catalog file for upload to your store.

Is it connected to a specific platform?

No. It works on catalog exports generically, so it can be used alongside Shopify, WooCommerce or marketplace workflows.
