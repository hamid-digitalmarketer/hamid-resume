Google Ads & PPC

Overview

PPC Waste Detector analyzes Google Ads and Meta search query data to identify wasted spend: negative-intent query bleed, cross-campaign keyword cannibalization, casual gaming display placements and click-fraud patterns. It exports negative keyword lists in Ads Editor CSV format.

Problem It Solves

A meaningful share of PPC budgets leaks into irrelevant queries and placements. Without systematic detection, managers keep paying for clicks that cannot convert.

Target Users

  • PPC managers and media buyers
  • Agencies running Google and Meta accounts
  • E-commerce and lead-gen teams

Key Features

  • Six waste detectors covering query intent, cannibalization and placements
  • Click-fraud pattern heuristics
  • Automated negative keyword list generation
  • Ads Editor CSV export
  • CLI interface with CI (ruff, mypy, pytest)

Technologies

  • Python
  • Typer
  • Pydantic
  • pytest
  • CSV tooling

Contribution & Skills

Sole author. Built the detection rules, query analysis pipeline, negative keyword generation and export formats.

Install & Usage

Install

git clone https://github.com/hamid-digitalmarketer/ppc-waste-detector.git
cd ppc-waste-detector
pip install -e ".[dev]"

Run an audit

ppc-waste audit
ppc-waste export-negatives --format ads-editor

FAQ

What counts as ad waste?

Negative-intent query bleed, cross-campaign keyword cannibalization, junk display placements (for example casual gaming apps) and click-fraud patterns.

Can I export the negative keywords?

Yes. The tool exports negative keyword lists in Ads Editor CSV format ready for account import.
