Overview

PPC Performance Dashboard is a Streamlit application for analyzing PPC campaign KPIs. It normalizes messy ad-platform exports, applies campaign and date-range filters, computes period comparisons and renders charts with Plotly. A bundled sample dataset provides an instant demo.

Problem It Solves

Raw ad-platform exports vary by platform and are messy to analyze. Managers need clean, comparable KPI views to spot performance changes quickly.

Target Users

  • PPC managers and analysts
  • Agencies reporting on client accounts
  • Growth teams

Key Features

  • Column normalization for varied exports
  • Campaign and date-range filters
  • Period-over-period KPI comparison
  • Plotly charts and aggregate reporting
  • Bundled sample data for instant demo
  • Test suite covering normalization, KPI math and filters

Technologies

  • Python
  • Streamlit
  • Pandas
  • Plotly
  • pytest

Contribution & Skills

Sole author. Built the data normalization layer, KPI calculations, filter logic, period comparison and Streamlit interface.

Install & Usage

Install

python -m venv venv
# Windows: venv\Scripts\activate  |  macOS/Linux: source venv/bin/activate
pip install -r requirements.txt

Run

streamlit run app.py
# choose bundled sample data for an instant demo

FAQ

Does it perform incrementality analysis?

No. It reports platform-reported metrics as-is. The repository explicitly documents this limitation; causal incrementality is handled by AI Marketing Mix Copilot.

What data can I load?

You can use the bundled sample data or upload your own campaign exports; unknown columns are ignored rather than guessed.
