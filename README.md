- **Lightning Fast Performance**: Pure semantic HTML5 and vanilla CSS3 with zero heavy framework overhead, delivering instant First Contentful Paint (FCP) and optimal Core Web Vitals.
- **Generative Engine Optimization (GEO)**: Entity-rich nested Schema.org JSON-LD structured data (`Person`, `WebSite`, `ProfilePage`, `ItemList`, and `FAQPage`) engineered for direct factual citations across ChatGPT, Google Gemini, Perplexity, and Claude.

## 💻 Local Development & Testing

```bash
# Clone the repository
git clone https://github.com/hamid-digitalmarketer/hamid-resume.git
cd hamid-resume

# Option 1: Serve locally via Python
python -m http.server 8080 --directory public
# Open http://localhost:8080 in your browser

# Option 2: Serve via Firebase CLI / Emulators
npx firebase-tools emulators:start --only hosting
```
